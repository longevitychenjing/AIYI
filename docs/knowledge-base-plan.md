# 卦象知识库实施决策

## 决策

知识库分为确定性事实层、编辑性直显层、可引证文本层和可选语义检索层。当前 Demo 使用 SQLite 作为本地权威库；Qdrant 只保存可由权威文本记录反查的向量副本。

第一期采用“64 卦全量索引 + 8 卦可引证 Demo 文本包”的范围，不制作伪全量解释。

## 来源约束

- 不抓取 Chinese Text Project。该站点明确禁止网页抓取；仅可作为人工核验链接。
- 文本必须来自允许程序获取的公开 API、定向导出或已获授权的数据包。
- 每次导入均记录来源 URL、获取时间、版本、许可依据、内容哈希和段落定位。
- 公开协作站点的文本在导入前必须确认当时的具体许可证与署名要求；不得仅因典籍年代久远就省略来源许可记录。

Wikisource 提供官方导出文件，但当前完整中文 Wikisource 正文导出约为 7.6 GB，不适合作为本项目的首期输入。第一期应使用定向的页面导出或 API 结果，并将取得的原始文件保存在受控目录中。

## 第一期开源数据范围

### 全量固定索引

覆盖全部 64 卦，不依赖外部文本：

- 六十四卦名称与二进制键；
- 上下卦；
- 本卦、变卦与动爻的确定性计算；
- 4096 个“本卦 + 动爻掩码”状态的可计算转换关系。

这部分来自项目内的确定性规则，绝不通过向量召回确定。

### 变卦直显

全部 64 卦在本地库中均有编辑性主题概要与“变入此卦时”的关注点。起卦后按本卦、变卦与动爻组合为直接展示文本，不预存 4096 条重复转换文案。

这类展示的 `provenance` 固定为 `editorial_demo`，必须与未来导入的经典原文引用分开呈现，不能标作典籍出处或确定性预测。

### 可引证 Demo 文本包

首批选择八卦，覆盖起始、推进、阻滞、冲突、协作与转化等常见体验：

| 卦 | 用途 |
| --- | --- |
| 乾 | 主动进取与自我约束 |
| 坤 | 承载、配合与顺势 |
| 屯 | 起始的困难与建立秩序 |
| 蒙 | 学习、启蒙与求教 |
| 需 | 等待、准备与时机 |
| 讼 | 分歧、边界与争执 |
| 泰 | 通达、协作与平衡 |
| 否 | 阻塞、隔绝与反思 |

每卦至少导入卦辞与六爻文本；可用的《彖》《象》作为独立记录导入。尚未有获核验来源的卦不得展示为“已有依据”，只能展示确定性的卦名、变卦和动爻。

## 语义码与向量案例

语义码优先于向量。第一版只使用受控码：

```text
domain: career | relationship | study | decision
phase: beginning | progressing | blocked | transition
concern: opportunity | risk | conflict | cooperation
stance: act | wait | learn | review
```

Demo 要准备 24 条人工编写的匿名测试问题，每个问题标注预期语义码、目标卦文本和理由。例如“新项目刚开始但资源不足，下一步该怎么安排”应映射为 `career + beginning + risk + learn`，并优先检索“屯”或“蒙”的已引证段落。

向量检索只用于以下对照评测：

- 同一语义但用词不同的问题能否找到相同的已引证段落；
- 向量结果是否会越过当前卦象的结构性过滤；
- 语义码筛选后向量排序，是否优于纯向量召回。

每个案例应保存 `query`、`expected_codes`、`expected_source_text_ids`、`must_not_return_ids`。这是一套检索评测数据，不是用户占问历史，也不应混入生产来源文本。

## 数据模型与验收

SQLite 的首批表为：

```text
hexagrams
hexagram_profiles
editions
source_texts
semantic_codes
text_semantic_codes
retrieval_cases
```

`source_texts` 的唯一性由 `edition_id + hexagram_id + line_position + text_kind` 保证；每条文本都必须有 locator 和 content_hash。

首期完成标准：

1. 64 卦可由现有规则计算和查询；
2. 八卦文本包可逐条定位到授权来源；
3. 起卦 API 对未覆盖文本明确返回“资料包尚未覆盖”，不生成伪引用；
4. 24 个检索案例可离线验证；
5. 只有通过案例基线后，才把文本同步到 Qdrant。

## 扩展阈值

Demo 文本包经人工核验后，以每批 8 卦扩展到全部 64 卦。只有在原文、注疏和现代授权资料合计超过约 2,000 个段落，或受控语义码无法覆盖超过 20% 的测试问题时，才把 Qdrant 作为常规检索路径启用。
