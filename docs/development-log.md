# 开发日志

## 2026-09-26 - 前端体验重构

### 待办：替换当前起卦页面视觉

当前的单屏双栏原型视觉过于平直，且把意图输入、投掷和解读同时放在同一界面，不符合目标体验。它仅保留为早期交互验证，不应作为正式页面方向。

### 已确认的三阶段流程

1. **意图页**：页面只呈现“在心中默念你的困惑，或者你最想知道的事。”和“起卦”命令，让用户先完成心理准备。
2. **起卦页**：左侧为三枚铜钱、投掷命令与手动录入入口；右侧为空白卦象。每次投掷从初爻向上填入一爻，用户可撤销最后一爻或通过手动面板修正任一爻。
3. **解读页**：完成六爻后进入。左侧纵向展示本卦和变卦（存在动爻时）；右侧为大模型对话区，并展示资料出处。

### 实现边界

- 三阶段流程是前端状态机；正式卦象计算仍由 FastAPI 返回，前端不得自行替代确定性排盘。
- 当前 `preview/three-step.html` 为零依赖的交互与视觉验证，解读与引用均明确标识为模拟数据。
- 当前正式前端保持为零依赖的 `preview/three-step.html`，通过 API 接入排盘、SSE 和 RAG。
